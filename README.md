# 👥 KeenKeeper

## 📌Description
KeenKeeper is a responsive friend management web app where users can track friends, log interactions (call, text, video), and view friendship analytics using charts and timeline history.

---

## 🛠️ Technologies Used
- React.js
- React Router DOM
- Tailwind CSS
- DaisyUI
- Recharts
- React Toastify
- React Icons

---

## ✨ Key Features

- 🧑 Friend management system using JSON-based data with detailed profile pages  
- ⚡ Call, Text, and Video interaction logging with automatic timeline updates  
- 📜 Timeline system to track all user interactions with date, icon, and title  
- 📊 Friendship analytics dashboard using Recharts pie chart visualization  
- 📱 Fully responsive design for mobile, tablet, and desktop devices  
- 🔔 Toast notifications for user actions like Call, Text, and Video
